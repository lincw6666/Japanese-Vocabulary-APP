# 📱 NotebookLM 手機隨身日文家教：完整操作指引手冊

歡迎使用基於 **Google NotebookLM** 的「情境導向日文家教系統」！
本方案**完全不需要安裝 Python、不需要申請 API Key**，只要透過手機瀏覽器（Safari / Chrome），即可隨時呼叫專屬家教！

---

## 🚀 三步快速建置流程（只需做一次）

### 第一步：在電腦或手機開啟 NotebookLM
1. 打開瀏覽器前往：[notebooklm.google.com](https://notebooklm.google.com)
2. 登入您的 Google 帳號。
3. 點選 **「+ 新建筆記本」 (New Notebook)**。
4. 將筆記本命名為：`🇯🇵 我的情境日語隨身家教`。

### 第二步：上傳知識庫來源 (Sources)
點選「新增來源」➔ 選擇「上傳檔案」，將本資料夾 (`NotebookLM_Package/`) 中的檔案上傳：
1. **必傳核心文件（黃金三核心）**：
   - `Source_Curriculum_and_Pragmatics.md`（大家日本語情境重構地圖與語用學雙軌對照）
   - `Source_Grammar_Mastery_Vault.md`（🌟 整合 12 大文法心態寶典：動詞變身穿睡衣、て形轉接頭、因為雙系統等）
   - `Source_Roleplay_Scripts.md`（🎭 沉浸式實戰劇本：含跟一年不見死黨東京一日遊、地鐵迷路、居酒屋破冰等）
2. **依目前學習級別上傳單字庫**：
   - 初學者上傳：`Source_Vocab_N5.txt`
   - 進階者可依序上傳：`Source_Vocab_N4.txt`、`Source_Vocab_N3.txt`、`Source_Vocab_N2.txt`、`Source_Vocab_N1.txt`

> 💡 **NotebookLM 殺手級技巧**：
> 左側來源清單可以隨時「打勾」或「取消勾選」。例如今天想專注練習 N5，就只勾選核心文件與 `Source_Vocab_N5.txt`，AI 就會 100% 只用 N5 單字出題與造句！

### 第三步：設定家教角色指令（點選「新增附註」！）
1. 打開 `NotebookLM_Tutor_Prompt.txt`，複製裡面的【家教大腦 System Instruction 內容】。
2. 在 NotebookLM 點選 **「新增附註」 (Add Note)**，標題填寫 `🤖 日語家教核心指令`，內文貼上提示詞儲存。
3. （可選）在左側來源清單中將這則附註**打勾**，NotebookLM 就會永久強制執行！

## 📱 手機日常實戰操作指令速查

在手機瀏覽器打開該筆記本，在下方輸入框直接發送指令：

| 輸入指令 | 家教動作示範 |
|---|---|
| **`/teach`** | **不知道要學什麼時直接打！** 家教會列出 8 大實戰情境菜單，並主動推薦你從【S01: 超商微波加熱與買袋】第一站開始！ |
| `/teach S01` | 解拆「超商與速食店點餐」文法、3-Tier 禮貌層級（丁寧/常體/死黨口語「チンして！」）、店員敬語聽力「袋はお分けしますか？」 |
| `/teach S03` | 解拆「居酒屋點餐結帳」，教你如何用「とりま生二つっしょ！」跟好朋友乾杯 |
| `/teach S04` | 解拆「飯店入住與行李寄存」，示範 ～てもいいですか 許可句型 |
| `/teach 第14課` | 查詢傳統教材課數，自動轉為旅遊生存實戰句型（動詞て形請求句） |
| `/quiz` | 自動從你勾選的單字庫中抽詞，生成旅遊情境填空或造句測驗 |
| `/listen` | 模擬店員/廣播說敬語，挑戰你的聽力理解與反應應對 |
| **`/roleplay`** | **全新對話模式！** 列出 R01~R04 劇本選單，特別推薦從 R01 與一年不見死黨一日遊開始！ |
| **`/roleplay R01`** | **進入死黨一日遊！** AI 化身一年沒見的留學死黨（健太/結衣），在八公像前驚呼開場，純聊不講課！ |
| **`/explain`** | **聊天中隨時喊停！** 當看不懂剛才那句時打 `/explain`，家教會暫停演戲，詳細拆解文法與重音！ |
| **`/continue`** | **無縫接續聊天！** 文法聽懂後輸入 `/continue`，AI 秒速切回死黨角色繼續陪你聊下一站！ |

## 🎧 額外彩蛋功能：生成日語雙人 Podcast (Audio Overview)
在 NotebookLM 筆記本的右側或上方，點擊 **「音訊總覽 (Audio Overview) ➔ 生成 (Generate)」**：
Google NotebookLM 會自動基於您上傳的日語情境重組文件，生成一段由兩位英文/日文 AI 主持人進行的深度討論 Podcast！
在通勤、搭捷運或散步時，戴上耳機就能隨身聆聽日語語用學、禮貌層級與日本旅遊文化解說！
